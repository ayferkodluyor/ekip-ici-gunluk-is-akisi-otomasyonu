# 📬 Ekip İçi Günlük İş Akışı Otomasyonu

Python, Pandas ve Streamlit kullanılarak geliştirilen, Excel tabanlı ekip görev takibi ve Outlook e-posta taslağı oluşturma uygulaması.

## 🎯 Projenin Amacı

Ekiplerin günlük iş takibinde karşılaştıkları tekrarlayan manuel işlemleri azaltmak, görevlerin zamanında takip edilmesini kolaylaştırmak ve çalışanlara özel e-posta taslakları hazırlamak.

## 🚀 Özellikler

- Excel dosyasından çalışan ve görev bilgilerini okuma
- İzinli çalışanları listeleme
- Geciken görevleri ve gecikme sürelerini hesaplama
- Bugün tamamlanması gereken işleri belirleme
- Önümüzdeki 7 gün içinde tamamlanacak görevleri listeleme
- Çalışan bazında kişiselleştirilmiş e-posta taslakları oluşturma
- Outlook Web üzerinde alıcı, konu ve mesaj içeriğini hazır açma
- Demo Modu ile test e-postalarını belirlenen adrese yönlendirme

## 🛠️ Kullanılan Teknolojiler

| Teknoloji | Kullanım Amacı |
|---|---|
| Python | Uygulama ve iş kuralları |
| Pandas | Excel verilerini okuma, filtreleme ve gruplama |
| Streamlit | Web arayüzü |
| Excel | Ekip ve görev verilerinin tutulması |
| Outlook Web | E-posta taslaklarının hazırlanması |

## ⚙️ Uygulama Nasıl Çalışır?

1. Kullanıcı, `Ekip Takip` sayfası bulunan Excel dosyasını yükler.
2. Uygulama gerekli sütunları ve e-posta adreslerini kontrol eder.
3. Çalışanların izin durumları ve görev tarihleri analiz edilir.
4. İzinli, geciken, bugünkü ve yaklaşan işlerin sayıları ekranda gösterilir.
5. Seçilen kategoriye göre e-posta taslakları hazırlanır.
6. Kullanıcı taslağı Outlook'ta açar, kontrol eder ve isterse gönderir.

Not: Uygulama e-postaları otomatik göndermez. Gönderim Outlook üzerinden kullanıcı onayıyla gerçekleştirilir.
